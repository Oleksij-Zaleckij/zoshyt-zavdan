# Зошит завдань — Telegram Mini App

Спільний список завдань для команди, який відкривається всередині Telegram.
Сервер перевіряє, що користувач — із вашої Telegram-групи, тож сторонні люди доступу не мають.

## Що потрібно
- акаунт Telegram;
- хостинг для Node.js 18+ **з постійним диском** (Railway, Fly.io, Render з платним диском або власний сервер). Безкоштовні плани без постійного диску стирають базу при перезапуску;
- доступ до сторінки по HTTPS (хостинги дають його автоматично).

## Крок 1. Створіть бота
1. У Telegram відкрийте @BotFather і надішліть `/newbot`.
2. Задайте назву й username. Збережіть **токен** (не показуйте його нікому).

## Крок 2. Підготуйте групу команди
1. Створіть групу в Telegram і додайте туди колег та свого бота.
2. Дізнайтеся id групи: додайте в групу бота @getidsbot (або схожого), він покаже id виду `-100…`. Потім його можна видалити.
3. Альтернатива без групи: збирайте id людей (їх показує @userinfobot) і передайте їх у `ALLOWED_USER_IDS`.

## Крок 3. Розмістіть застосунок
1. Завантажте цю папку в репозиторій GitHub (або використайте інструмент хостингу для завантаження).
2. Створіть на хостингу новий сервіс із цього репозиторію. Команда запуску: `npm start`.
3. Підключіть постійний диск (volume), змонтований, наприклад, у `/data`.
4. Задайте змінні середовища:
   - `BOT_TOKEN` — токен із кроку 1;
   - `TEAM_CHAT_ID` — id групи з кроку 2;
   - `ALLOWED_USER_IDS` — (необов’язково) додаткові id через кому;
   - `DB_PATH` — наприклад, `/data/zoshyt.db`.
5. Отримайте адресу сервісу, вона починається з `https://`.

## Крок 4. Підключіть застосунок до бота
1. У @BotFather надішліть `/newapp`, оберіть свого бота.
2. Вкажіть назву, опис, (фото можна пропустити) і **адресу сервісу** з кроку 3.
3. Вкажіть коротку назву, наприклад `zoshyt`: BotFather дасть пряме посилання `https://t.me/ВАШ_БОТ/zoshyt`.
4. Надішліть це посилання в групу. Колеги відкривають зошит одним дотиком.
5. За бажанням: `/setmenubutton` у @BotFather додасть кнопку відкриття в чаті з ботом.

## Перевірка
Відкрийте посилання з кроку 4 у Telegram, додайте завдання. Нехай колега відкриє його зі свого акаунта: список має збігатися. Якщо бачите «Немає доступу», перевірте `TEAM_CHAT_ID`, що бот доданий у групу, і що ви самі в групі.

## Резервна копія
Усі завдання лежать в одному файлі бази (`DB_PATH`). Регулярно копіюйте його.

## Локальний запуск (для розробника)
```
npm install
BOT_TOKEN=... ALLOWED_USER_IDS=ваш_id npm start
```
Для перевірки в Telegram потрібна публічна HTTPS-адреса (наприклад, через тунель).
